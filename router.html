FAQ

Questions, answered.

How is this different from a Cloudflare redirect?

No Workers, no DNS, no JS to paste. Router is a no-code dashboard inside Framer: pick a country, choose a destination, activate. The geo lookup runs on the Vanssay backend from the visitor's real IP. You never touch code or API keys.

What's a "suggestion banner"?

Instead of forcing a redirect, Router can show a small, dismissible banner suggesting the better-matched page (like Airbnb). The visitor decides, which bounces far fewer people, and their choice is remembered so they're never asked twice.

Will my UTM / campaign tracking survive?

Yes. Turn on "Preserve query / UTM params" and Router carries the visitor's query string onto the destination URL, so your analytics and ad attribution keep working through the redirect.

Can people dodge it with a VPN?

On Pro and up, enable VPN-aware rules: the backend flags anonymising proxies and datacenter IPs (the same engine as Vanssay Bouncer), so geo rules can't be bypassed with a VPN.

Does one subscription cover multiple sites?

Yes, your plan is tied to your Vanssay account, not a project, and it's the same login as every other Vanssay plugin.
